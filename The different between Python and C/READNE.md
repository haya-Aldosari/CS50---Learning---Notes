## Python vs C

The video compares **Python** and **C** and explains that choosing a programming language depends on what we want to build.

---

## Syntax

The first comparison is the **syntax** of both languages.

Python generally requires less code to express the same idea, while C requires more explicit syntax.

---

## Compiler vs Interpreter

The video compares how both languages execute code:

```text
C      → Compiler
Python → Interpreter
```

This difference affects how programs are translated and executed.

---

## Speed

A speed test is performed between Python and C to compare their execution performance.

The video uses this comparison to show that programming languages can behave differently in terms of execution speed.

## Uses of Python

It also discusses the different fields and applications where **Python** is commonly used.

## POP vs OOP

The video introduces two programming approaches:

```text
POP → Procedure-Oriented Programming

OOP → Object-Oriented Programming
```

### POP

The program is organized mainly around **procedures and functions**.

### OOP

The program is organized around **objects**.

The appropriate language depends on the problem and the type of application being developed.
